# Сценарий видео-демо (до 3 минут)

1. Открыть `http://localhost:8501`.
2. Выбрать `open-001`, вопрос «Содержит ли документ все обязательные сведения по Положению?», нажать «Обработать документ». Показать карточку, источники и подсветку.
3. Выбрать `open-011` (заявление) и спросить «Укажи значение поля «Учебная группа»».
4. Выбрать `open-021` (практика) и проверить комплектность кнопкой «Проверить комплектность».
5. На любом документе спросить «Какова стоимость обучения?» — честный отказ.
6. Загрузить свой JPG/PNG при наличии.
7. Показать выгрузку JSON.
